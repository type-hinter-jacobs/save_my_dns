## IMPORTANT REQUIREMENTS ##

# Purpose
The purpose of this project is to create a DNS filtering system specifically designed to block pornographic content on the internet. Currently the scope is to block access to pornographic websites. As exposure to technology is increasing at younger ages, so is exposure to pornographic content also increasing; therefore it is imperative to develop accessible means as to stop this growing epidemic.


# Core Requirements
-> The system must give users ontrol over which domains are blocked and/or accessible.

-> Users must have an some way to interface with the system, to handle access and blocking of domains.

-> Users must be able to add or remove domains to be blocked.

-> The system must be able to log user actions and keep track of domains that are flagged as pornographic.

-> The system must have a built in feature or switch to block all known pornographic domains.
